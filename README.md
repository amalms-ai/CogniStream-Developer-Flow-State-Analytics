# CogniStream: Developer Flow-State & Cognitive Load Analytics

## Project Overview

CogniStream is a data analytics project that explores software developers' work patterns, focus time, interruptions, task switching, and self-reported cognitive workload.

The project uses Python to generate and analyze sample developer activity data. The results will be presented through visualizations and an interactive dashboard.

## Project Objectives

- Analyze developer focus time and work sessions.
- Examine interruptions and task-switching patterns.
- Explore self-reported cognitive workload.
- Perform data cleaning and exploratory data analysis.
- Create meaningful visualizations and an interactive dashboard.
- Generate data-driven insights to support better work practices.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Jupyter Notebook
- Scikit-learn
- Git and GitHub
